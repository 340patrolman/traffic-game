# SEOUL PATROL (traffic-game) v0.6

브라우저에서 바로 실행되는 3인칭 교통경찰 순찰 게임. 빌드 도구 0, 서버 0, 외부 에셋 0.
`index.html`을 열면 실행되고, GitHub Pages(main / root)에 그대로 올린다. 폰 홈 화면에 설치(PWA)하면 단독 앱처럼 실행된다.

- 지도 한 장: **시내**(왕복 2·4차로, 신호·횡단보도·어린이보호구역, 중심부 고층 타워 스카이라인) → **IC 8곳**(동·서·남·북·북동·북서·남동·남서, 연결로 + 우회전 진입·진출 램프) → **순환고속도로**(왕복 6차로, 1차로 버스전용, 100) → 다시 시내. 도로는 끊기지 않는다(스텁 끝 차단봉, 다리 위 높이 보정, 빠지면 「마지막 도로로 복귀」).
- 남동쪽 언덕에 **연습 서킷**(직선·헤어핀·S·스위퍼, 연석·출발선·러버콘).
- 모드 4종: **순찰 근무**(6분, 점수) · **자유 주행**(시간 제한·감점 없음, 순환고속도로 랩 타임) · **연습 서킷**(교통 없음, 코너 앞 권장 속도·슬로우 인·패스트 아웃·카운터 스티어 코칭, 랩 타임) · **학습 12항목**(교통사고 12대 중과실 카드 → 「게임에서 체험하기」).
- 지도는 **서울 강남·서초 축약판**: 반포대로·논현로·강남대로·언주로·선릉로(남북) × 사평대로·도산대로·서초대로|테헤란로·역삼로·남부순환로(동서), 강남역 사거리가 중심. 모든 시내 도로 왕복 4차로(막다른 길 없음), 북쪽 한강과 다리(한남대교·반포대교 이름), 남쪽 경부고속도로, 순환고속도로 북쪽 호는 올림픽대로. 제한속도: 간선 50 · 어린이보호구역 30(논현로·역삼로 학교 옆) · 교외 60 · 올림픽대로 80 · 고속도로 100. 랜드마크 5곳(무역센터형 타워·전시장, 법원, 예술의전당형 돔, 강남대로 쌍둥이 타워, 원형 경기장). 실존 상호·로고는 없다.
- 날씨·시간대: 맑음 · 석양 · 밤(가로등·전조등·창문 불빛) · 비(그립 78%) · 눈(그립 62%) · 강풍(옆바람에 차가 밀림) · **자동**(기기 시계·계절로 정함, 네트워크 없음) · **랜덤**(근무마다). 타이틀과 일시정지 메뉴에서 바꾼다.
- 미니맵: 터치(클릭)하면 ×1 → ×2 → ×4 확대(플레이어 중심), PC 는 +/- 키. 차내 시점의 내비 화면에도 같은 지도가 나온다.
- 순찰차 3종(중형 세단 · 전기 SUV · 대형 세단): 둥근 단면 로프트 차체, 흰 차체 + 청색 띠 + 황색 선, 엠블럼·「경찰 POLICE」, 경광등 바(카메라 돔). 실존 차명은 쓰지 않는다.
- 시점 2종: 추적(3인칭) / 차내(1인칭: 순찰차 사진을 참고한 실내 — 디지털 계기판, 중앙 내비(실시간 지도), 조수석 단속 단말(MDT), 룸미러·블랙박스, 좌우 사이드미러(실제 뒤 풍경), 동승 경찰관). 차내에서 화면을 좌우로 드래그하거나 Q/E 로 둘러본다. 가로 화면 「광각 3면」은 실험 옵션.
- 단속: 지나가는 **차량·보행자를 터치(클릭)** → 「무슨 위반?」 객관식 → 정답이면 차량은 우측으로 정차(그 뒤 갓길에 안전하게 서면 고지 완료), 보행자는 계도. 위반 종류: 신호위반·보행자 보호의무·중앙선·버스전용차로·무단횡단(횡단보도 밖, §10)·보행자 신호위반(횡단보도 위 보행 적색, §5). 법조항·범칙금은 `data/laws.json`(T-Book 참고값, 「확인 중」).
- 주행 보조: 차선 유지 보조(조향을 놓으면 차로 중앙으로, 끌 수 있음), 속도 감응 조향, 언더스티어·오버스티어(제동 중·미끄러운 노면), 경사, **노말/스포츠 주행 모드**(일시정지 메뉴 · N), **감속 시점 안내**(앞 신호가 적·황이면 「지금 감속 — 정지선 Xm · 정지거리 Ym」, 굽은 길은 권장 진입 속도).
- **방향지시등**: , / . 키 또는 조이스틱 위 ◀ ▶ 버튼. 램프가 깜빡이고 HUD 화살표가 켜진다. 회전이 끝나거나 8초 뒤 자동 해제. 4차로에서 **방향지시등 없이 차로를 바꾸면 −3**, 교차로 앞 실선 구간(정지선 30m 안)에서 바꾸면 −5(경광등 추격 중 특례).
- AI 차량도 회전·차로 변경 때 방향지시등을 켠다. 단속 소재: **방향지시등 없이 차로 변경 · 실선 구간 차로 변경 · 운전 중 휴대전화(밝은 화면) · 차 밖으로 꽁초 던지기(떨어지는 불씨) · 동물을 안고 운전(창가의 강아지)** — 터치하면 객관식 보기에 나온다. 법조항은 `data/laws.json`(확인 중).
- IC 안내표지: 연결로 입구 「순환고속도로 → ○○IC · 방면」, 분기 54m 전 「↱ ○○IC 진입」, 순환고속도로 출구 500m·직전 「↗ ○○IC 출구」(서초IC 예술의전당·법원 방향, 반포IC 고속터미널·반포대교 방향, 한남IC, 삼성IC, 청담IC, 수서IC, 양재IC, 경부고속도로 시점).
- 소리: 전부 합성(엔진·EV 인버터·바람·사이렌·충돌·UI) + 인트로 테마(드론·금관 패드·팀파니·라이저) + 확성기(내장 음성).

## 실행

- 파일로: `index.html` 더블클릭. file:// 에서는 `data/laws.json` fetch 가 막혀 범칙금·벌점·학습 카드가 「확인 중」/빈 화면으로 보인다.
- 정적 서버로: `실행.bat`(Windows) 또는 `tools/serve.ps1`, GitHub Pages: https://340patrolman.github.io/traffic-game/
- 처음 열면 인트로(도로교통법의 목적 → 교통경찰 → 타이틀). 화면을 한 번 터치하면 테마 음악이 난다(브라우저 자동재생 정책). 탭·Esc·Space 로 건너뛴다. `?nointro=1` 로 생략.

## 규칙 요약(순찰 근무)

- 근무 6분. 점수 = 단속(정답 +30, 부분 정답 +10, 위반 없음 정답 +5 / 무작위 단속 −5) + 고지 완료 +10 + 보행자 계도 + 안전 주행 감점.
- 플레이어의 신호위반·과속(제한 + 11)·중앙선 침범·차량 접촉·코너 이탈은 감점. 경광등을 켜고 쫓는 동안 특례. 사람을 치면 즉시 근무 종료.
- 자유 주행·연습 서킷은 사고 외 감점이 없다(안내만).

## 법령 수치

`data/laws.json` 한 곳. `verified:false` 는 「확인 중」. T-Book 참고값은 `candidate`. 12대 중과실 카드는 `study12`. 게임은 법령의 정본이 아니다 — T-Book 이 정본.

## 저장

localStorage `tg_` 접두사만(`tg_settings`, `tg_best`, `tg_last`, `tg_bestlap_free`, `tg_bestlap_circuit`). `tb_` 키는 읽지도 쓰지도 않는다.

## 디버그·확인

- `?test=1` — 인트로 생략 + `TG.test.*` 훅(`start`, `startMode(car, mode)`, `step(초)`, `setPlayer`, `spawnCarAt`, `spawnOnLink`, `spawnPedAt`, `setSignal`, `override`, `ticketChoose`, `scenario(id)`, `lap()`, `pano()`, `render`, `info`, `state`, `city/traffic/peds/signals/terrain/game/camera/settings`).
- `?norender=1` — 루프에서 그리지 않는다(헤드리스 검증용, `render()` 로만 그린다).
- 헤드리스 검증: 저장소 밖 `_verify.html`/`_ic.html`(index.html + `_*_tail.js`)을 `chrome --headless=new --use-angle=swiftshader --virtual-time-budget=4000 --dump-dom` 으로 열어 `<pre id="VOUT">` 를 읽는다. `_ic_tail.js` 는 IC 8곳의 연결로·램프 32구간과 링 한 바퀴를 자동 조종으로 실제 주행해 끊김·빠짐을 잡는다.
- `?stress=1` — 교통·행인 최대치 + `[perf]` 로그.

## 구조

`js/config.js` → `city.js`(격자·`frameAt`) → `world.js`(도심 메시·타워) → `terrain.js`(지형·링·IC 8곳·램프·서킷·강·바다·하늘) → `weather.js`(날씨·시간대) → `signals.js` → `vehmesh.js`(차량 로프트·실내) → `vehicle.js`(플레이어 물리·계기판·거울) → `traffic.js` → `peds.js` → `enforcement.js`(터치 단속 퀴즈) → `study.js`(12항목 카드) → `hud.js` → `minimap.js` → `input.js` → `main.js`(루프·모드·랩·코칭·인트로·테스트 훅). 전부 고전 `<script>`(모듈 없음). 스크립트 주소에 `?v=버전` 을 붙여 캐시를 갈아끼운다(배포 때 sw.js CACHE 와 함께 올린다).
