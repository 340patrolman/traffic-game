# SEOUL PATROL (traffic-game) v0.10.58

브라우저에서 바로 실행되는 3인칭 교통경찰 순찰 게임 + 서울 서초구 공공데이터 지도.
빌드 도구 0 · 서버 0 · 실행 중 네트워크 요청 0(자료는 받은 날의 값을 `data/` 에 구워 둔다).
`index.html`을 열면 실행되고, GitHub Pages(main / root)에 그대로 올린다. 폰 홈 화면에 설치(PWA)하면 단독 앱처럼 실행된다.

- 주소: https://340patrolman.github.io/traffic-game/
- 법령 정본은 **T-Book**(자매 앱)이다. 이 게임의 조문·범칙금·벌점은 `data/laws.json` 한 곳에 T-Book·국가법령정보센터 원문에서 옮겼고, 확인 안 된 값은 화면에 「확인 중」으로 보인다.

## 규칙 요약

- 순찰 근무 6분. 단속 정답·고지 완료·현장 안전조치·112 출동·영상 단속에 점수, 신호위반·과속·중앙선·차량 접촉에 감점. 사람을 치면 즉시 근무 종료.
- 긴급자동차 특례(도로교통법 제30조)는 긴급 용도 + 경광등·사이렌일 때만. 적색 교차로는 서행, 어린이보호구역 제한속도는 특례 없음.
- 추격은 대응 원칙(등급 A 만 · 안전거리 · 무전 공조)이고, 어린이보호구역으로 도주하면 **추격 중지가 정답**이다(+45 · 스탬프).
- 근무 시계는 처음 조작할 때 선다 — 그 전에는 점수가 변하지 않는다.

## 실행

- 파일로: `index.html` 더블클릭(file:// 에서는 fetch 가 막혀 법령·공공데이터가 「확인 중」/빈 층으로 보인다).
- 정적 서버로: `tools/serve.ps1`, 또는 GitHub Pages.

## 저장

localStorage `tg_` 접두사만. `tb_`(T-Book) 키는 읽지도 쓰지도 않는다.

## 디버그·확인

- `?test=1` — 인트로 생략 + `TG.test.*` 훅(`startMode(car, mode)`, `step(초)` 등).
- `?nointro=1` · `?map=<id>` · `?sim=1`(시드 고정 시뮬레이션) · `?norender=1`(헤드리스).
- 헤드리스 검증: 저장소 밖 `_verify.html`(index.html + `_verify_tail.js`)을 크롬 headless 로 열어 `<pre id="VOUT">` 를 읽는다 — 네 지도 각각. 지도 점검은 `tools/map-audit.js`.

## 구조

고전 `<script>` 순서 로드 · 전역 `TG`(file:// 실행 때문에 ES module 을 쓰지 않는다) · three.js r128 1개(`lib/`). 자세한 판별 기록은 `CLAUDE.md`, 앞으로의 일은 `ROADMAP.md`.
