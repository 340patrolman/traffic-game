# 순찰길 (traffic-game) v0.2

브라우저에서 바로 실행되는 3인칭 교통경찰 순찰 게임. 빌드 도구 0, 서버 0, 외부 에셋 0.
`index.html`을 열면 실행되고, GitHub Pages(main / root)에 그대로 올린다.

- 지도 한 장에 세 구간: **시내**(이면도로 왕복 2차로 + 가운데 간선 왕복 4차로, 신호·횡단보도·어린이보호구역) → 동쪽 출구 → **교외 굽은 길**(왕복 2차로, 언덕·강 다리, 60) → **순환고속도로**(왕복 6차로, 1차로 버스전용, 100) → 북쪽 출구(진입로, 80) → 시내. 로딩 없이 이어진다. 고속도로는 한 번 올라타면 계속 돌 수 있고 동·북 두 출구로 시내에 돌아온다.
- 위반 3종을 목격해 단속: 신호위반(적색에 정지선 통과), 보행자 보호의무 위반(횡단보도에 보행자가 걷는데 그대로 통과), 고속도로 버스전용차로 위반. 목격한 차량 위에 주황 화살표, 미니맵에도 점으로 표시.
- 시점 2종: 추적(3인칭) / 차내(1인칭: 운전석 눈높이, 실시간 계기판, 룸미러·좌우 사이드미러에 실제 뒤 풍경). 화면 오른쪽 위 미니맵(도시·순환고속도로·강, 내 위치·위반 차량·정차 대상).
- 소리: 엔진·바람·도심 웅웅거림·타이어·경광등 사이렌·충돌·UI 전부 합성. 정차 유도 시 확성기(PA) 안내는 브라우저 내장 음성(오프라인, 파일 없음)으로 「앞 차량, 우측 가장자리에 정차하십시오」.
- 주행이 1순위: 정지거리(속도의 제곱), 앞차와의 초 단위 간격, 코너 한계(언더스티어), 경사(오르막·내리막)가 결과로 따라온다. 교차로 우회전은 30km/h 여유, 40km/h 아슬아슬, 50km/h 는 밀려난다.
- 단속: 위반을 **직접 목격한** 차량 뒤에 경광등을 켜고 붙으면 우측(갓길)으로 정차한다. 그 뒤 갓길에 안전하게 서면 10초 고지 미니게임. 신호위반(시내)·버스전용차로 위반(고속도로) 2종. 무단횡단 보행자 옆에 경광등 켜고 서면 「계도」.
- 배경: 산·구릉·논밭·강·바다·하늘·구름, 도심 아파트(동 번호)·상가 간판·전봇대·버스정류장, 차량 6종 실루엣(세단·해치·SUV·밴·트럭·버스), 팔다리가 움직이는 보행자.

## 실행

- 파일로: `index.html` 더블클릭 (Chrome·Edge·Firefox). file:// 에서는 브라우저가 `data/laws.json` fetch를 막으므로 범칙금·벌점이 「확인 중」으로 보인다.
- 정적 서버로: 폴더를 아무 정적 서버로 열면 laws.json까지 읽는다. (GitHub Pages가 이 경우)
- 처음 열면 인트로(도로교통법의 목적 → 교통경찰 → 타이틀)가 나오고, 탭·Esc·Space로 건너뛴다. `?nointro=1` 로 생략.

## 조작

| 동작 | 터치(폰) | 키보드(PC) |
| --- | --- | --- |
| 조향 | 왼쪽 원형 조이스틱 좌우 | ← → / A D |
| 가속 | 조이스틱 위 또는 오른쪽 ▲ 가속 | ↑ / W |
| 브레이크 | 조이스틱 아래 또는 ■ 브레이크 | ↓ / S / Space |
| 후진 | ▼ 후진(거의 정지 상태에서) · 브레이크를 정지 후 0.35초 더 | R 또는 ↓ 계속 누름 |
| 경광등·사이렌 | 경광등 버튼 | L |
| 시점 전환(추적 3인칭 ↔ 차내 1인칭) | 「시점」 버튼 · 타이틀에서 선택 | C |
| 교육 안내 켜고 끄기 | 일시정지 메뉴 | H |
| 일시정지 | ❚❚ | Esc / P |

후진 중 멈추려면 후진 버튼(↓)을 떼거나 가속을 누른다. 후진등(흰색)이 켜지고 HUD에 「R 후진」이 뜬다.
원형 조작판과 ▲■▼·경광등 버튼은 PC에서도 항상 보이며 마우스로 누를 수 있고, 키보드 입력도 원판의 금색 스틱에 그대로 비친다.

## 규칙 요약

- 근무 1회 6분. 점수 = 단속 점수(정답 +30, 오답 +10, 위반 없음 −5) + 보행자 계도(+8) + 안전 주행 감점.
- 목격한 위반(HUD 「위반 의심」 + 화살표)만 단속 대상. 위반 없는 차를 세우면 「위반 없음 — 안내 후 귀가」.
- 플레이어 본인의 신호위반·과속(구간 제한속도 + 11)·중앙선 침범·차량 접촉·코너 이탈은 즉시 감점(「경찰이 먼저 지킨다」). 경광등을 켜고 위반 차량을 쫓는 동안 신호·속도 특례. 사람을 치면 즉시 근무 종료. 물에 빠지면 마지막 도로 위치로 복귀.
- 고속도로 1차로(청색 선)는 버스전용. 승용차가 달리면 위반 목격 대상.

## 법령 수치

`data/laws.json` 한 곳에만 둔다. `verified:false` 항목은 화면에 「확인 중」으로 보인다. T-Book 에서 옮겨 온 참고값은 `candidate` 필드에 있고 화면에는 「확인 중 · T-Book 참고값」으로 함께 표시된다. 소유자가 별표 원문과 대조해 `verified:true` 로 확정한다. 게임은 법령의 정본이 아니다 — T-Book 이 정본.

## 저장

localStorage 키는 `tg_` 접두사만 쓴다(`tg_settings`, `tg_best`, `tg_last`). `tb_` 키는 읽지도 쓰지도 않는다.

## 디버그·확인

- `?stress=1` — 교통·행인 최대치. 프레임이 떨어지면 콘솔에 `[perf]` 로그와 함께 스폰 예산이 줄고 그림자가 꺼진다(있는 것은 지우지 않음).
- `?test=1` — 인트로 생략 + `TG.test.*` 훅. 예: `TG.test.start('sedan')`, `TG.test.step(초)`(rAF 무관 결정적 진행), `TG.test.setPlayer(x,z,heading,speed)`, `TG.test.spawnLead(gap, speed)`, `TG.test.brakeCar(id)`, `TG.test.spawnCarAt(x,z,dir,node,v,violator,straight)`, `TG.test.spawnOnLink('ring', i, dirA, lane, v, type)`, `TG.test.setSignal(i,j,'v'|'h','red')`, `TG.test.spawnPedAt(x,z,axis,coord,side,d,jaywalker)`, `TG.test.simulateSlow(ms)`, `TG.test.state()`, `TG.test.info()`.
- `?touch=1` — 데스크톱에서 터치 UI 강제.

## 구조

`js/config.js` 수치 → `city.js` 도로망(격자 + 링크 좌표계 `frameAt`) → `world.js` 도심 메시 → `terrain.js` 지형·순환도로·램프·물·하늘
→ `signals.js` 신호 → `vehmesh.js` 차량 실루엣 → `vehicle.js` 플레이어 물리 → `traffic.js` AI(격자·링크·램프·위반) → `peds.js` 행인(관절·무단횡단)
→ `enforcement.js` 목격→정차→고지 → `hud.js` → `input.js` 조이스틱·버튼·키보드 → `perf.js` → `save.js` → `main.js` 루프·규칙·인트로.
전부 고전 `<script>` 로드(ES module 아님: file:// 에서도 실행되기 위해). `ref/`는 참고 clone, 배포 제외.
