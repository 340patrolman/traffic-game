## 고친 방식

1. **되풀이되는 경고는 💭 안내 줄로** — 처음 한 번만 안내문, 그 뒤는 💭(정차 자리 2.5→4초 · 무단횡단 6→8초).
2. **연달아 뜨던 두 줄을 한 줄로** — 뒤 글이 앞 글을 스스로 덮고 있었다(정차 유도+앰프 · 위반 확인+앰프 · 하차 3줄 · 시작 2줄).
3. **표시 시간 상한을 `hud.notice` 한 곳에서** — alert 3200 · bad 3000 · warn·good 2400 · info 2200ms. **게임 설계값**이다.
4. **긴 설명은 💭·목표 줄로** — 112 신고 · 영상 기록 · 현장 발견 · 사건 사슬 목표(목표는 `#missionBar` 에 계속 떠 있다).
5. 법령 문구는 한 자도 줄이지 않았다 — 고지 카드·학습 화면이 정본이다.

## 남은 것

통과선 0.15 까지 가려면 **단속 고리 자체**(위반 의심 → 위반 확인 → 앰프 → 감점)를 안내문이 아니라 **임무 피드**로 돌려야 한다.
그것은 「가르치는 방식」을 바꾸는 일이라 **소유자 결정 전에는 하지 않는다.**
